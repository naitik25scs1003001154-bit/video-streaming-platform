# Video Streaming Platform

## Description

A video streaming platform that allows users to upload, manage, and stream video content.

## Technologies Used

- Python
- Flask
- FFmpeg
- AWS S3
- SQLite

## Features

- User registration and login
- User dashboard
- Video upload
- Video management
- Video streaming
- Video processing using FFmpeg
- Cloud storage using AWS S3
- SQLite database

## Project Outcome

A user dashboard where users can manage their uploaded videos and view video streams.

This project was developed as part of an internship.
